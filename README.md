# Template Auto Build

HTMLファイルから目次ページを自動生成する、シンプルな静的サイト用テンプレートです。

外部ライブラリを使用せず、Node.jsのみで動作します。
Vercelと連携することで、GitHubへのPushからビルド・デプロイまで自動化できます。

## 主な機能

- HTMLファイルの自動取得
- `<title>` タグからページタイトルを取得
- ファイル名によるカテゴリ分類
- タイトル・ファイル名による検索
- カテゴリによる絞り込み
- 静的ファイルの自動コピー
- ビルド時の出力ディレクトリ初期化
- Vercelによる自動ビルド・デプロイ

## ディレクトリ構成

```text
.
├── __work/
│   ├── 00_example.html
│   ├── 01_example.html
│   └── 02_example.html
├── image/
│   └── icon.png
├── build.cjs
├── vercel.json
├── README.md
└── public/          # ビルド時に自動生成
```

## 動作環境

- Node.js 22以上（推奨）

外部ライブラリのインストールは不要です。

## 使用方法

### 1. HTMLファイルを配置する

`__work/` ディレクトリにHTMLファイルを配置してください。

目次に表示されるタイトルは、各HTMLファイルの `<title>` タグから取得されます。

### 2. ビルドする

```bash
node build.cjs
```

### 3. 生成結果を確認する

`public/index.html` をブラウザで開いてください。

なお、Vercelへデプロイする場合は自動的にビルドされるため、手動でのビルドは不要です。

## カテゴリの設定

ファイル名の先頭2文字を使用してカテゴリを分類します。

| 接頭辞 | カテゴリ                     |
| ------ | ---------------------------- |
| 00     | アーキテクチャ・サーバー構築 |
| 01     | フロントエンド               |
| 02     | バックエンド・DB             |
| その他 | その他                       |

上記は設定例です。

カテゴリは `build.cjs` 内の `groups` を編集することで自由に変更できます。

```js
const groups = {
  "00": "カテゴリA",
  "01": "カテゴリB",
  "02": "カテゴリC",
};
```

## カスタマイズ

`build.cjs` 内のHTMLテンプレートや設定を編集することで、以下の項目を変更できます。

- サイトタイトル
- デザイン・レイアウト
- カテゴリ
- 検索・絞り込み機能
- ファビコン

## デプロイ

本テンプレートは、Vercelへのデプロイに対応しています。

### Vercelの設定

`vercel.json` に以下の設定を記述済みです。

```json
{
  "$schema": "https://openapi.vercel.sh/vercel.json",
  "framework": null,
  "buildCommand": "node build.cjs",
  "outputDirectory": "public"
}
```

デプロイ時に `build.cjs` が自動実行され、目次HTMLの生成と静的ファイルのコピーが行われます。

### デプロイ手順

1. 本テンプレートを使用してGitHubリポジトリを作成する。
2. Vercelにログインする。
3. 対象のGitHubリポジトリをインポートする。
4. Deployを実行する。

`vercel.json` にビルド設定を記述済みのため、基本的に追加のビルド設定は不要です。

### デプロイ後の更新方法

GitHub連携後は、対象ブランチへのPushに応じて自動的にビルド・デプロイされます。

```text
HTMLファイルの追加・編集
        ↓
GitHubへコミット・Push
        ↓
Vercelによる自動ビルド
        ↓
目次HTMLの生成
        ↓
自動デプロイ
        ↓
サイト更新完了
```

生成された `public/` を手動で編集・アップロードする必要はありません。

## 注意事項

- `public/` はビルドのたびに削除・再生成されます。
- HTMLファイルの追加・編集は `__work/` 内で行ってください。
- 目次の生成対象は `__work/` 直下のHTMLファイルです。
- 未定義のカテゴリは「その他」として表示されます。
- `__work/` と `image/` ディレクトリは事前に作成してください。
- 両ディレクトリ内のファイルは公開対象となるため、機密情報を含めないでください。
